# 运行说明（本地启动与验收）

> 环境：Windows，Node.js ≥ 24，MongoDB 8.x（mongod / mongosh 已加入 PATH）。

## 一、启动 MongoDB（本项目专用数据目录）

- 数据目录：`D:\MongoDB\survey-data`（专用于本项目；**不要**使用或修改其他 MongoDB 数据目录）。
- 启动：双击 `scripts\start-mongo.bat`，等价命令：
  `mongod --dbpath "D:\MongoDB\survey-data" --port 27017 --bind_ip 127.0.0.1 --logpath "D:\MongoDB\survey-data\mongod.log" --logappend`
- 若 27017 已有本项目 mongod 在运行，再次启动会因锁文件占用退出（无害）。
- 验证：`mongosh --quiet --eval "db.runCommand({ping:1})" mongodb://127.0.0.1:27017/admin` 返回 `{ ok: 1 }`。

## 二、启动后端

```
cd D:\问卷\server
npm install        # 仅首次
npm start          # 默认 http://localhost:3000
```

- 环境变量（可选）：`PORT`、`MONGODB_URI`、`MONGODB_DB`、`SESSION_SECRET`。
- 数据库：主库 `survey_system`；测试库 `survey_system_test`（每次测试前自动清空重建）。

## 三、浏览器验收（第一条完整业务链）

1. 打开 http://localhost:3000 → 注册账号 A（用户名 3–20 字符，密码 ≥ 6 位），自动登录进入"我的问卷"。
2. 创建问卷：填标题、说明（可勾选"允许匿名填写 / 允许重复填写"）→ 创建。
3. 在问卷列表点击该问卷的蓝色按钮「**管理 / 编辑题目**」（或点击问卷标题）进入题目编辑页。**添加题目、配置跳转、发布问卷都在这个页面里**：页面顶部有操作栏（＋添加题目 / 发布问卷 / 关闭问卷），草稿问卷也可用下方的"添加题目"表单与"发布与分享"区。草稿问卷的填写链接在发布后才可用。
4. 在题目编辑页选择题型添加题目：
   - 单选 / 多选：选项每行一个（至少 2 个）；多选可设最少 / 最多选择数（两者相同即"必须选择指定数量"）；
   - 文本：可设最少 / 最多字数；数字：可设最小值 / 最大值、"必须为整数"；
   - 勾选必答 → 添加。
   - 跳转规则（仅单选 / 多选 / 数字，目标必须是其后面的题）：在题目下方配置"当 [条件]，跳转到 [目标题]"；可添加多条（按顺序匹配，首条命中生效），支持上移 / 下移 / 编辑 / 删除。文本题不支持跳转；非法配置（目标不存在、跳到前面、条件选项无效、运算符非法等）会被服务端拒绝。
5. 点"发布问卷"（页面顶部操作栏或"发布与分享"区均可）→ 页面显示填写链接（如 `http://localhost:3000/survey/<问卷id>`），可复制。
6. 退出登录，注册账号 B → 打开填写链接 → 按题目逐步作答：回答后自动按跳转规则显示下一题（"上一题"可回退修改，回退后原路径上的答案自动作废）→ 提交 → 显示"提交成功"。
   - 故意填错（如多选超出数量、数字非整数、文本过短）或伪造被跳过题目的答案 → 提交被服务端拒绝，错误信息指出具体题目与原因。
   - 同一账号再次提交 → 提示"您已提交过该问卷"（问卷未勾选重复填写时）。
7. 用账号 A 登录 → 问卷列表点"统计" → 应看到：总答卷数、单选各选项人数、多选各选项选择次数、文本内容、数字平均值，均与真实提交一致（被跳过的题不计入回答人数，不写死）。
8. 生命周期验收：
   - 管理页设"截止时间"（本地时间输入框，留空 = 不设）→ 保存。填写页显示截止时间；到点后填写页显示"问卷已截止"且提交被拒绝；改晚截止时间（延期）或清除后恢复。过去时间与乱填格式会被服务端拒绝。
   - "关闭问卷"→ 填写者打不开（"问卷已关闭"）也提交不了；关闭后问卷保持关闭（如需再次收集，请新建问卷）。
   - 题目编辑/删除/排序、重新开放、复制问卷已按需求收敛移除，页面上不再有这些入口（对应 API 返回 404）。

## 四、运行测试

```
cd D:\问卷\server
npm test
```

- 需要本地 MongoDB 运行中；使用 `survey_system_test` 库，运行前自动清空。
- 覆盖：注册登录、创建问卷、添加题目（含并发添加回归）、结构校验、发布锁定（Q5）、跳转（规则存储与结构校验、单选/多选 any/all/数字六种运算符、优先级、跳过必答、伪造路径、路径外答案不入统计）、四种题型校验（必答/多选数量/文本字数/数字范围与整数/无效选项与类型）与统计、重复限制（Q6）、匿名（Q1）、截止时间与关闭、已移除接口（重开/复制/题目编辑/删除/排序）返回 404。

## 五、停止

- 后端：Ctrl+C（或结束 node 进程）。
- MongoDB：双击 `scripts\stop-mongo.bat`（等价 `mongosh --eval "db.adminCommand({shutdown:1})" mongodb://127.0.0.1:27017/admin`）。
