# 需求说明

- 版本：v0.2
- 日期：2026-10-16
- 状态：第 1 节为已明确需求；第 3 节为业务规则第一版（2026-10-16 用户确认）；第 2 节为建议方案（统计口径细节待对应题型实现时确认）；第 4 节为需求未覆盖的信息；第 5 节为实现进度。

## 1. 明确需求

### 1.1 用户与权限

- 注册、登录；记录用户名、密码凭证（哈希存储）和注册时间。
- 用户只能管理自己创建的问卷、查看自己问卷的统计。
- 其他用户可以通过分享链接登录后填写问卷（填写一律需要登录，见 Q1）。

### 1.2 问卷管理

- 问卷字段：标题、说明、是否允许匿名填写。
- 操作：问卷列表、创建、发布、设置截止时间、关闭、独立填写链接。

### 1.3 题型与配置（必须能通过编辑界面配置）

| 题型 | 可配置项 |
| --- | --- |
| 单选 | 选项；是否必答 |
| 多选 | 选项；是否必答；最少选择数 / 最多选择数 / 必须选择的数量（恰好） |
| 文本 | 是否必答；最少 / 最多字数 |
| 数字 | 是否必答；取值范围；是否必须为整数 |

### 1.4 题目跳转

- 支持根据单选、多选、数字的答案配置跳转。
- 默认按题目顺序填写；命中规则时自动跳转。
- 规则必须通用（数据驱动），不能针对具体问卷写死。

### 1.5 填写与提交

- 填写时提示错误；提交时校验并保存答卷。
- 支持多人同时填写。
- 支持匿名填写（按问卷设置；语义见 Q1：答卷不记录 respondentId）。
- 支持同一人重复填写（按问卷设置）。

### 1.6 统计（必须基于真实答卷计算，不得写死示例数据）

- 单选：各选项选择人数、该题回答人数。
- 多选：各选项被选择次数。
- 文本：填写内容。
- 数字：平均值。
- 支持整卷统计和单题统计。

### 1.7 技术与数据约束

- 持久化业务数据一律使用 MongoDB；不用关系数据库；不用文件替代业务数据库；不用现成问卷框架。
- 源代码、配置、文档、日志和测试输出保存为项目文件。
- 前端可以简单，功能必须可操作。
- 代码职责清晰：题型、校验、跳转、提交策略、统计可局部修改；规则参数由数据配置。
- 后续迭代保留已有核心功能和数据，考虑兼容或迁移；不为未知需求过度设计。

### 1.8 开发记录与验证

- 每轮维护 `docs/ai-log.md`，记录规则见 `CLAUDE.md`。
- 同步维护系统说明、数据库设计、API、关键逻辑及运行说明。
- 测试至少覆盖：创建问卷、添加题目、跳转、校验、提交、统计；记录步骤、输入、预期输出、实际输出与结果；不得虚构结果。

## 2. 建议方案

### 2.1 技术栈（已按此实施）

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 后端 | Node.js 24 + Express 5 + 官方 `mongodb` 驱动 | Node 24 已安装；官方驱动让文档结构与设计文档一一对应，不引入 ORM 抽象层 |
| 前端 | 静态 HTML/CSS/JS + fetch，Express 托管，无构建步骤 | 问卷 UI 交互简单，原生 JS 足够；后续需要再迁框架，API 不变 |
| 认证 | `bcryptjs` 密码哈希 + `express-session` + `connect-mongo` 会话 | 会话存 MongoDB，服务重启不丢登录态 |
| 测试 | Node 内置 `node:test` + 真实本地 mongod（`survey_system_test` 库） | 零额外测试框架依赖；在真实数据库上验证索引与查询行为 |

### 2.3 统计口径（已按此实现）

- "该题回答人数" = 提交的答卷中 answers 含该题 questionId 的数量（被跳过的题不计入；到达并作答才计入）。
- 多选"被选择次数" = 每份答卷对同一选项至多计 1 次（答卷内重复选项在校验层拒绝，天然去重）。
- 数字"平均值" = 该题所有数值答案的平均，分母为该题作答人数。
- 文本 = 各答卷的填写内容列表。
- 重复填写（allowRepeat=true）时每份答卷各计一次。

## 3. 业务规则（第一版 · 2026-10-16 用户确认）

| 编号 | 事项 | 确认内容 |
| --- | --- | --- |
| Q1 | 匿名与登录 | 填写一律需要登录；"允许匿名"仅表示答卷不记录 respondentId（存 null）。匿名答卷不适用重复限制。 |
| Q2 | 多选跳转匹配 | 支持 any / all 两种匹配方式（matchMode），默认 any。 |
| Q3 | 规则优先级 | 按编辑器中的规则顺序求值，首条命中即跳转；规则支持调整顺序。 |
| Q4 | 循环跳转 | 禁止；只允许向后跳转，保存问卷时校验（目标存在且位于当前题之后）。 |
| Q5 | 发布后修改 | 发布后题目结构锁定（题目/选项/跳转不可改）；标题、说明、截止时间允许修改。 |
| Q6 | 重复填写 | 不允许重复填写时，第二次提交被拒绝（不覆盖第一次答卷）；允许时每份各计一次。 |
| Q7 | 截止时间 | 提交时惰性判断 deadline（过期拒绝提交，无需定时任务）；允许延期（修改截止时间）。 |
| Q8 | 数字跳转运算符 | 支持 =、≠、<、≤、>、≥ 六种；该题未填不参与跳转。 |
| Q9 | 用户名与密码 | 用户名 3–20 字符且唯一、不含空白；密码至少 6 位；不设置邮箱。 |

主要影响（确认时已说明）：匿名答卷无法去重、所有者看不到其身份（Q1）；Q5 下改题需在发布前完成（发布后锁定）；Q6 下误提交无法自行修改（后续迭代可考虑撤回重填）。

> 注（2026-10-17 范围收敛）：原始需求未要求"复制问卷""重新开放问卷""题目编辑/删除/排序"，上述功能已按需求收敛移除（API 与前端入口一并删除），Q5/Q7 表述已相应调整；关闭后的问卷保持关闭。详见 `docs/ai-log.md` 第 12 轮。
